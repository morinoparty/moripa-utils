# お問い合わせ (Ticket)

不具合の報告や質問など、運営に伝えたいことがある場合は `/ticket` コマンドからお問い合わせを送信できます。
送信したお問い合わせは「チケット」として番号 (例: `#12`) が付けられ、運営からの返信もゲーム内で確認できます。

## 送信する

1. チャットで `/ticket` を実行すると、お問い合わせ用の画面が開きます。
2. カテゴリーを選び、お問い合わせ内容を入力して「送信」を押します。
3. 送信が完了すると、チャットにチケット番号が表示されます。

内容は空にはできず、最大 1000 文字まで入力できます。
送信時にいた場所も一緒に運営へ伝わるため、不具合が起きた場所で送信すると対応がスムーズになります。

## 確認する・やり取りする

| コマンド | 説明 |
|---------|------|
| `/ticket list [ページ] [--status <open \| closed>]` | 自分が送信したチケットを新しい順に表示します。 |
| `/ticket view <番号>` | チケットの内容と最新のコメントを表示します。 |
| `/ticket comment <番号>` | チケットにコメントを書き込みます。運営への追加の情報や返信に使います。 |
| `/ticket close <番号>` | 解決したチケットをクローズします。クローズしたチケットを再オープンできるのは運営のみです。 |

`<番号>` は Tab キーで補完できます。
`/ticket view` で表示されるチケットには、`[コメントする]` などのボタンが付くため、クリックで操作することもできます。

## 運営からの通知

サーバーにいる間に次のことが起きると、チャットで通知されます。
通知の `[表示]` をクリックすると、そのチケットが表示されます。

- 運営がチケットに返信したとき
- 運営がチケットをクローズ / 再オープンしたとき

<Callout type="warn">
オフラインの間に届いた返信は、ログイン時には通知されません。返信を待っている場合は `/ticket list` で確認してください。
</Callout>
