# MoripaUtils

MoripaUtils は、morinoparty の Minecraft サーバー (Paper) およびプロキシ (Velocity) の運営に必要な機能をまとめたユーティリティプラグインです。
機能 (feature) ごとに独立したパッケージとドキュメントを持ち、1 つの JAR で複数の機能を提供します。

## 機能

| 機能 | 対象 | 内容 |
|------|------|------|
| [Observability](/docs/observability) | Paper / Velocity | サーバーとプロキシの稼働状況を Prometheus 形式で公開し、Grafana で可視化できるようにする |
| [Ticket](/docs/ticket) | Paper | `/ticket` コマンドから運営へ問い合わせを送信できる UI を提供する (MineAuth 導入時は HTTP API から自分のチケットを参照できる) |
| [お知らせ](/docs/announcement) | Velocity | プロキシに接続している全プレイヤーへ、用意したメッセージを一定の間隔で送る |

また、このドキュメントサイトでは morinoparty の [mpm リポジトリ](/docs/mpm-repository) インデックスもホストしています。

サーバーで遊ぶプレイヤー向けの使い方は、[プレイヤー向けガイド](/docs/player) にまとめています。

## モジュール構成

- `common` - Paper/Velocity 共通コード
- `paper` - Paper (Bukkit) プラグイン
- `velocity` - Velocity プロキシプラグイン
- `api` - 外部プラグイン向け公開 API

## 使い方

プラグインの JAR は [GitHub Releases](https://github.com/morinoparty/moripa-utils/releases) から入手できます。
はじめて導入する場合は、JAR の配置から Prometheus の設定までを一通り説明している [Getting Started](/docs/observability/getting-started) から読み進めてください。
設定ファイル (`config.conf`) の構成は [設定ファイル](/docs/config) にまとめています。

### JAR の更新

サーバーまたはプロキシの稼働中に、`plugins` ディレクトリの JAR を削除したり新しいバージョンの JAR に置き換えたりしても、稼働中のプラグインはそのまま動作を続けます。
起動時に JAR を開いたままにしておき、JAR 内のファイルをその開いたファイルから読み込むためです。
新しい JAR は、次にサーバーまたはプロキシを再起動したときに読み込まれます。

<Callout type="warn">
この動作は、削除されたファイルを開いたまま読み続けられる Linux / macOS を前提としています。
Windows では稼働中の JAR を削除できないため、サーバーまたはプロキシを停止してから置き換えてください。
</Callout>
