# World Tree

World Tree は、ロビーにある世界樹の葉を季節に合わせて置き換える機能です。
サーバーの起動時に現在の月から季節を選び、WorldEdit を使って葉のブロックを置き換えます。
コマンドを使うと、季節をその場で切り替えることもできます。

<Callout type="info">
この機能は Paper でのみ動作します。
使用するには、WorldEdit または FastAsyncWorldEdit (FAWE) を導入し、`config.conf` の `worldTree.enabled` を `true` にする必要があります。
</Callout>

<Callout type="warn">
この機能はロビーサーバー専用です。
`worldTree.enabled` はデフォルトで `false` のため、ロビーサーバーの `config.conf` でだけ有効にしてください。
ほかのサーバーで有効にすると、設定した範囲内のブロックが置き換えられる可能性があります。
</Callout>

## 仕組み

世界樹の葉は、季節に依存しない「中間ブロック」(デフォルトでは黒曜石、赤色の羊毛、作業台、クォーツブロック) で作られています。
季節を切り替えるときは、どの季節からでも必ず次の順序で置き換えます。

1. 範囲内のブロックを数え、中間ブロックとすべての季節のブロックの合計が `worldTree.expectedBlockCount` と一致することを確認します。
2. すべての季節のブロックを、中間ブロック (各種類が同じ割合) に戻します。
3. 範囲内のブロックを数え直し、季節のブロックが残っていないことと、中間ブロックの数が `worldTree.expectedBlockCount` と一致することを確認します。
4. 中間ブロックを、目的の季節のブロック (設定した重みの割合) に置き換えます。

季節のブロックを中間ブロックに戻すときは、ブロックの状態 (葉の `distance` など) を区別せず、種類だけで対象を判定します。
白色の色付きガラスのように複数の季節で使われる種類は、数えるときに 1 回だけ数えます。

デフォルトの季節は以下のとおりです。

| 季節 | 月 | 置くブロック |
|------|----|-------------|
| `spring` | 3 - 4 月 | 桜の葉 60%、開花したツツジの葉 15%、白色の色付きガラス 15%、桃色の羊毛 10% |
| `summer` | 5 - 9 月 | オークの葉 35%、シラカバの葉 25%、ツツジの葉 25%、緑色の羊毛 15% |
| `autumn` | 10 - 11 月 | 赤色のポプラの葉 30%、橙色のポプラの葉 30%、黄色のポプラの葉 40% |
| `winter` | 12 - 2 月 | トウヒの葉 40%、粉雪 25%、ペールオークの葉 25%、白色の色付きガラス 10% |

葉は `persistent=true` の状態で置かれるため、時間が経っても消えません。

## サーバーの起動時の動作

サーバーの起動後、最初のティックで、現在の月に対応する季節を反映します。
月は `worldTree.timeZone` (デフォルトは `Asia/Tokyo`) のタイムゾーンで判定します。
すでにその季節のブロックだけになっている場合は、何も変更しません。

この処理は、サーバーの起動時にのみ実行されます。
`/mu reload` で設定を再読み込みしても実行されないため、コマンドで手動で切り替えた季節は再読み込み後も維持されます。
ただし、次回のサーバーの起動時には、現在の月の季節に置き換えられます。

## コマンド

| コマンド | 権限 | 説明 |
|---------|------|------|
| `/mu worldtree set <季節>` | `moripautils.worldtree.manage` (デフォルトは OP のみ) | 世界樹を指定した季節にします。すでにその季節の場合も、中間ブロックに戻してから置き直します。 |
| `/mu worldtree auto` | `moripautils.worldtree.manage` (デフォルトは OP のみ) | 世界樹を現在の月の季節にします。すでにその季節の場合は何も変更しません。 |

季節の名前は `worldTree.seasons` の `name` で指定します。Tab キーで補完できます。
どちらのコマンドもコンソールから実行できます。
コマンドで切り替えた季節は、次回のサーバーの起動時に現在の月の季節に置き換えられます。

`worldTree.enabled` が `false` の場合や、WorldEdit / FAWE が導入されていない場合は、実行時にその旨が表示されます。

## 安全確認

意図しない範囲のブロックを書き換えないよう、以下の場合は処理を中止し、サーバーのログに警告を出力します。
プラグイン自体は無効化されず、他の機能はそのまま動作します。

| 状況 | 動作 |
|------|------|
| 範囲内の葉の数 (中間ブロックとすべての季節のブロックの合計) が `worldTree.expectedBlockCount` と一致しない | 何も変更しません。ログに種類ごとの数を出力します。 |
| 設定したブロックの名前や状態を WorldEdit が解釈できない (サーバーのバージョンに存在しないブロックなど) | 何も変更しません。ログに解釈できなかったブロックを出力します。 |
| 中間ブロックに戻した後、季節のブロックが残っている、または中間ブロックの数が一致しない | 中間ブロックの状態で止めます。ログに残っているブロックと数を出力します。 |
| `worldTree.world` のワールドが読み込まれていない | 何も変更しません。 |

範囲内で葉を追加または削除した場合は、`worldTree.expectedBlockCount` を新しい葉の数に合わせてください。
葉の数は、WorldEdit で範囲を選択し、中間ブロックとすべての季節のブロックの種類をまとめて数えると確認できます。
デフォルトの設定では、以下のコマンドで確認できます。

```text
//count obsidian,red_wool,crafting_table,quartz_block,cherry_leaves,flowering_azalea_leaves,white_stained_glass,pink_wool,oak_leaves,birch_leaves,azalea_leaves,green_wool,red_poplar_leaves,orange_poplar_leaves,yellow_poplar_leaves,spruce_leaves,powder_snow,pale_oak_leaves
```

`//count obsidian,red_wool,crafting_table,quartz_block` のように中間ブロックだけを数える方法は、世界樹が中間ブロックの状態のときにだけ使えます。
季節のブロックに置き換わっている状態では、中間ブロックの数はほぼ 0 になります。

世界樹の葉以外でも、範囲内に置かれている中間ブロックや季節のブロック (`white_stained_glass` や `green_wool` など) はすべて数に含まれます。
範囲内の別の場所にこれらのブロックを置くと数が一致しなくなり、処理が中止されます。

ブロックの置き換えはメインスレッドで行います。
範囲は約 130 万ブロックあるため、置き換えの間はサーバーが一時的に停止することがあります。

## 設定

`config.conf` の `worldTree` ブロックで設定します。

| キー | デフォルト | 説明 |
|------|-----------|------|
| `worldTree.enabled` | `false` | world tree 機能を有効にするかどうかです。 |
| `worldTree.world` | `world` | 世界樹があるワールドの名前です。 |
| `worldTree.pos1` / `worldTree.pos2` | `{ x=43, y=102, z=54 }` / `{ x=-79, y=183, z=-77 }` | 世界樹を囲む範囲の、対角にある 2 つの角の座標です。 |
| `worldTree.timeZone` | `"Asia/Tokyo"` | 現在の月を判定するタイムゾーンです。 |
| `worldTree.expectedBlockCount` | `19984` | 範囲内にある葉 (中間ブロックとすべての季節のブロックの合計) の数です。1 以上を指定する必要があります。 |
| `worldTree.intermediateBlocks` | `[obsidian, red_wool, crafting_table, quartz_block]` | 中間ブロックの種類です。重複させることはできず、季節のブロックと同じ種類も使用できません。 |
| `worldTree.seasons` | 4 件 (上記参照) | 季節の一覧です。 |

`worldTree.seasons` の各要素は以下のキーを持ちます。

| キー | 説明 |
|------|------|
| `name` | 季節の名前です。コマンドの引数に使用します。英小文字、数字、ハイフン (`-`)、アンダースコア (`_`) のみ使用でき、季節間で重複してはいけません。 |
| `months` | この季節にする月 (`1` から `12`) です。1 月から 12 月のそれぞれを、ちょうど 1 つの季節に割り当てる必要があります。 |
| `palette` | 置くブロックの一覧です。各要素は `block` (WorldEdit の書式のブロック。`[]` で状態を指定できる) と `weight` (重み。1 以上の整数) を持ちます。各ブロックは、重みの合計に対する割合で選ばれます。 |

```text
worldTree {
    enabled = true
    world = world
    seasons = [
        {
            name = spring
            months = [3, 4]
            palette = [
                { block = "cherry_leaves[persistent=true]", weight = 60 }
                { block = "flowering_azalea_leaves[persistent=true]", weight = 15 }
                { block = "white_stained_glass", weight = 15 }
                { block = "pink_wool", weight = 10 }
            ]
        }
        # summer / autumn / winter も同様に記述します
    ]
}
```

`seasons` を記述すると、デフォルトの季節はすべて置き換えられます。
一部の季節だけを記述した場合は、1 月から 12 月のすべてを割り当てていないため、設定の読み込み時にエラーになります。
