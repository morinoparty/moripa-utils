# 公開 API

MoripaUtils は、他のプラグインから機能を使用するための公開 API (`api` モジュール) を提供しています。
`api` モジュールは [GitHub Packages](https://github.com/morinoparty/moripa-utils/packages) で配布しています。
リリースを公開すると、GitHub Actions が自動的に publish します。

## 依存関係の追加

GitHub Packages のリポジトリを追加し、`party.morino:moripa-utils-api` に依存します。
バージョンには GitHub のリリースのタグから `v` を除いたもの (例: タグ `v0.1.11` なら `0.1.11`) を指定します。
MoripaUtils 本体が実行時に API のクラスを提供するため、`compileOnly` で依存してください。

```kotlin title="build.gradle.kts"
repositories {
    maven("https://maven.pkg.github.com/morinoparty/moripa-utils") {
        // GitHub Packages は公開パッケージでも取得に認証が必要
        credentials {
            username = providers.gradleProperty("gpr.user").orElse(providers.environmentVariable("GITHUB_ACTOR")).orNull
            password = providers.gradleProperty("gpr.key").orElse(providers.environmentVariable("GITHUB_TOKEN")).orNull
        }
    }
}

dependencies {
    compileOnly("party.morino:moripa-utils-api:0.1.11")
}
```

### 認証

GitHub Packages の Maven リポジトリは、公開パッケージであっても取得に GitHub のトークンが必要です。

| 環境 | 設定 |
|------|------|
| 手元 | `read:packages` 権限を持つトークンを `~/.gradle/gradle.properties` の `gpr.user` (GitHub のユーザー名) と `gpr.key` (トークン) に設定します。GitHub CLI を使っている場合は、`gh auth token` で表示されるトークンも使えます。 |
| GitHub Actions | ワークフローに `permissions: packages: read` を付け、`GITHUB_ACTOR` と `GITHUB_TOKEN` (`secrets.GITHUB_TOKEN`) を環境変数に設定します。 |

```properties title="~/.gradle/gradle.properties"
gpr.user=<GitHub のユーザー名>
gpr.key=<read:packages 権限を持つトークン>
```

API のクラスは Java 25 向けにコンパイルされています。
また、API は MoripaUtils の有効化後に使用できるため、MoripaUtils への依存関係を宣言してください。
Paper では `plugin.yml` や `paper-plugin.yml` に、Velocity では `@Plugin` アノテーションの `dependencies` に `moripa-utils` を指定します。

## API の取得

API は Paper / Velocity で共通の `MoripaUtilsAPI` と、Paper 専用の機能を含む `MoripaUtilsPaperAPI` に分かれています。
どちらも `getInstance()` で取得し、機能ごとのプロパティから各機能の API を使用します。

| プロパティ | 取得元 | 説明 |
|-----------|--------|------|
| `ticket` | `MoripaUtilsAPI` / `MoripaUtilsPaperAPI` | チケットの閲覧・クローズ・コメントを行います。詳細は [チケットの公開 API](./ticket/api) を参照してください。 |
| `schematic` | `MoripaUtilsPaperAPI` | schematic のアップロードを行います。Paper でのみ使用できます。詳細は [Schematic](./schematic#公開-api) を参照してください。 |

```kotlin
// Paper / Velocity の両方で使用できる
val api = MoripaUtilsAPI.getInstance()
// Paper でのみ使用できる (Velocity で呼ぶと IllegalStateException になる)
val paperApi = MoripaUtilsPaperAPI.getInstance()
```

API のメソッドは `CompletableFuture` で結果を返します。
`CompletableFuture` はメインスレッド以外で完了する場合があるため、完了後に Bukkit の API を使用する場合は、メインスレッドに戻してから実行してください。
